# My-SQL_projects
“I worked on an E-Commerce Sales Analysis project using Python and MySQL. The main objective was to analyze e-commerce transaction data and generate useful business insights about customers and sales performance.

First, I used Python and Pandas to load and prepare the transaction data, and then imported the data into MySQL for SQL-based analysis.

In MySQL, I used SQL concepts such as SUM, AVG, COUNT, GROUP BY, ORDER BY, CASE statements, subqueries, and window functions like RANK.

I analyzed customer spending, identified the highest-spending customers, found customers with the highest average purchase amount, and segmented customers into High Spenders and Medium Spenders. I also performed country-wise sales analysis.

From the analysis, France generated the highest total sales, while the USA had the highest average purchase amount.

This project helped me understand how Python can be used for data preparation and SQL can be used for data analysis and extracting business insights.”
